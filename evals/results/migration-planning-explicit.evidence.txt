+Applies-To: store.py, test_store.py

+## Context
+
+存储对象是本地的小型字典，公开入口只有 `save(path, values)` 与 `load(path)`，没有按键查询或部分更新接口。

+## Decision
+
+目标使用 Python 标准库 `sqlite3`，每个调用方指定的路径对应一个数据库文件，无新增依赖。
+采用单行快照表，完整字典仍经 `json.dumps` / `json.loads` 编解码，以保留现有 JSON 可表示值、嵌套结构和键转换语义。

+```sql
+CREATE TABLE IF NOT EXISTS store_snapshot (
+    id INTEGER PRIMARY KEY CHECK (id = 1),
+    payload TEXT NOT NULL
+);
+```
+
+`save` 在打开数据库前完成序列化，在同一事务内建表并以参数绑定写入或替换 `id = 1` 的快照，成功提交后返回 `None`；失败回滚，连接在所有路径上关闭。
